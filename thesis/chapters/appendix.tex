\section{Prompt Templates}
\label{app:prompts}

This section reproduces the prompt templates used by the two generative ranking baselines
(Section~\ref{subsec:method-baselines}) and the input template used by the supervised trace scorer
(Section~\ref{subsec:method-scorer}). Braces denote fields substituted at run time. All prompted
baselines additionally use the system message

\begin{quote}\ttfamily\small
You are a careful multilingual fact-checking assistant. Return strict JSON only.
\end{quote}

\noindent
and are decoded greedily, so the only source of variation between runs is the input itself.

Use the claim and the evidence snippets to judge which reasoning traces are most reliable.\newline
Rank all candidate traces from best to worst. The input order is arbitrary and must not be copied unless it is truly the best ranking.\newline
A better trace is one that is better supported by the evidence, checks the claim more directly, and reaches a more reliable verdict.\newline
\newline
There are \{num\_traces\} traces indexed 0 through \{num\_traces-1\}.\newline
The ranked\_trace\_indices value must be a permutation containing each of these indices exactly once: [\{valid\_indices\}].\newline
Do not omit indices. Do not repeat indices. Do not use placeholder indices.\newline
Then predict the final verdict for the claim.\newline
\newline
Allowed verdict labels: \{allowed\_labels\}\newline
\newline
Return strict JSON only with this schema:\newline
\{"ranked\_trace\_indices":[...],"predicted\_verdict":"\textless one allowed label\textgreater"\}\newline
Do not include markdown. Do not include any explanation.\newline
\newline
Claim:\newline
\{claim\}\newline
\newline

\end{table}

\section{Technical Information}
\label{app:technical}

All experiments were run on NVIDIA A100 GPUs on the institutional cluster, with distributed
data-parallel training across two GPUs via \texttt{torchrun} for the main trace-scorer runs and a
single GPU for inference and smaller ablations. Table~\ref{tab:technical} lists the software
environment. Together with the code and configuration files in the project repository, these versions
are intended to make the reported results reproducible: model behaviour under quantized fine-tuning is
sensitive to the exact versions of \texttt{transformers}, \texttt{peft}, and \texttt{bitsandbytes} in
particular.
